# Prompts para Documento sobre Generación de Datos Sintéticos

## Prompt 1: Estructura y Planificación
```
Actúa como un experto en seguridad y crea una estructura detallada para un documento técnico sobre generación de datos sintéticos en el contexto de LLMs. Incluye: introducción, fundamentos técnicos, técnicas principales, aplicaciones prácticas, herramientas, casos de estudio, consideraciones éticas y conclusiones. Para cada sección, proporciona 3-4 subtemas clave.
```

## Prompt 2: Introducción y Fundamentos
```
Redacta una introducción técnica sobre la generación de datos sintéticos para LLMs. Define qué son los datos sintéticos, su clasificación (totalmente sintéticos, parcialmente sintéticos, aumentados) y las ventajas que ofrecen respecto a privacidad, control y reducción de sesgos. Menciona el contexto regulatorio (GDPR, CCPA) que hace relevante esta tecnología.
```

## Prompt 3: Técnicas de Generación
```
Describe las principales técnicas para generar datos sintéticos: GANs, modelos autoregresivos y VAEs. Para cada técnica, explica su funcionamiento técnico, fortalezas y debilidades. Incluye un ejemplo de código para GANs aplicado a texto. Adicionalmente, describe técnicas específicas para texto como fine-tuning de LLMs preentrenados, paráfrasis y generación basada en templates con ejemplos de código usando Hugging Face.
```

## Prompt 4: Aplicaciones Prácticas
```
Analiza aplicaciones prácticas de datos sintéticos con LLMs: 1) Entrenamiento y fine-tuning (escasez de datos, mitigación de sesgos, personalización vertical); 2) Evaluación de modelos (evaluación controlada, robustez, detección de sesgos); 3) Casos específicos (entrenamiento multilingüe, simulación de conversaciones). Incluye un ejemplo de generador de datos para un dominio médico.
```

## Prompt 5: Herramientas y Ecosistema
```
Enumera y analiza las principales herramientas disponibles para generación de datos sintéticos: plataformas comerciales (Gretel.ai, MOSTLY AI, Hazy), soluciones open source (SDV, Ydata-synthetic) y herramientas para datos textuales (Hugging Face, NLPAug). Para cada categoría, proporciona ejemplos de código o configuración y compara sus ventajas técnicas.
```

## Prompt 6: Casos de Estudio
```
Desarrolla tres casos de estudio sobre implementaciones reales de datos sintéticos: 1) Registros médicos sintéticos por Syntegra; 2) El enfoque de OpenAI para RLHF con datos sintéticos; 3) Uso de datos financieros sintéticos en entornos bancarios. Para cada caso, detalla el problema, la metodología y los resultados obtenidos.
```

## Prompt 7: Desafíos y Ética
```
Analiza los principales desafíos técnicos y éticos: 1) El equilibrio entre utilidad y privacidad; 2) Evaluación de calidad; 3) Representatividad y sesgos; 4) Transparencia; 5) Consentimiento y propiedad intelectual; 6) Marco regulatorio. Incluye un ejemplo conceptual de código para evaluar riesgos de privacidad en datos sintéticos.
```

## Prompt 8: Conclusiones y Futuro
```
Sintetiza el impacto transformador de los datos sintéticos en el desarrollo de LLMs: democratización, protección de privacidad y personalización. Identifica direcciones futuras prometedoras: integración de privacidad diferencial, generación multimodal coherente y evaluación estandarizada. Incluye referencias técnicas relevantes y actuales.
```
