# Janier Chará Cardona - De-identificación de Datos

## Prompt 1: Definición y Conceptos Básicos

```
Como experto en ciberseguridad especializado en IA:

1. Define el concepto de de-identificación en el contexto de LLMs
2. Explica la diferencia entre anonimización y seudonimización
3. Describe los principales tipos de información personal identificable (PII) que deben ser protegidos
4. Menciona las regulaciones principales que requieren de-identificación de datos
```

## Prompt 2: Técnicas y Herramientas

```
Como experto en implementación de soluciones de privacidad:

1. Describe las principales técnicas de de-identificación:
   - Generalización
   - Supresión
   - Seudonimización
   - Agregación
2. Menciona al menos 3 herramientas comerciales y 2 open source para de-identificación
3. Proporciona ejemplos de código para cada técnica
```

## Prompt 3: Casos de Uso y Mejores Prácticas

```
Como consultor de privacidad de datos:

1. Describe 3 casos de uso reales de de-identificación en LLMs
2. Explica las mejores prácticas para:
   - Evaluación de riesgos
   - Selección de técnicas
   - Verificación de efectividad
3. Proporciona ejemplos de métricas para medir la efectividad de la de-identificación
```

## Prompt 4: Desafíos y Soluciones

```
Como experto en privacidad de datos:

```
